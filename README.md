Так как некоторые моменты не описаны в задании, что и как делать, пришлось импровизировать

Стили карточки товара при наведении я задал свои, так как не увидел в макете какие они должны быть, так же хедеру добавил зеленую рамку снизу, чтобы он не сливался с карточками при скролле, ну и задал кнопкам активное состояние 
из макета.

Функционал: 
  - товар в корзину добавляется из карточки товара при клике по кнопке Add to cart в нужном количестве из счетчика
  - товар удаляется из корзины: 1) при обнулении счетчика в самой корзине 2) при клике по кнопке In cart из карточки товара (в таком случае счетчик обнулять не нужно, товар в любом количестве удалится из корзины) и счетчик в карточке товара не может быть меньше 1, это сделал специально
  - корзина открывается и закрывается только при клике по кнопке Cart, эта фича дает возможность взаимодействовать со страницей при открытой корзине, редактировать список добавленных товаров из корзины, и видеть общую стоимость, вместо того чтобы корзина закрывалась по клику вне области корзины.
  - так же был добавлен максимальный лимит каждого продукта он равен 10
